# MoldForge WebUI

A browser front-end for [MoldForge](https://github.com/Plesuro/MoldForge): upload
a 3D model, configure every panel parameter, and generate printable molds on a
headless Blender engine — no Blender UI needed.

**[Read the full documentation →](README-WEBUI.md)**

```bat
setup.bat   :: one-time: clone add-on, venv, portable Blender (~390 MB), vendor files
run.bat     :: starts http://127.0.0.1:8000 and opens the browser
```
